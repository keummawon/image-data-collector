# Image Data Collector (인공지능 이미지 데이터 수집)

웹캠으로 인공지능 학습용 이미지 데이터를 모으는 웹 페이지입니다.

## 기능
- 범주/클래스 이름을 입력하고 웹캠으로 사진 찍기 (한 번 클릭 1장, 길게 누르면 연속 촬영)
- 이미지 크기 선택 (224 / 400 / 640px, 정사각형), 좌우 반전
- 찍은 사진 목록 확인, 크게 보기, 삭제 (키보드 ← → / Delete)
- 저장: 크롬·엣지(PC)는 연결한 폴더에 `클래스이름/1.jpg, 2.jpg ...`로 바로 저장, 그 외 브라우저는 ZIP으로 다운로드

## 사용법
`index.html`을 크롬에서 열거나 GitHub Pages로 배포해서 사용하세요.

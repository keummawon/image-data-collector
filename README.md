# Image Data Collector (인공지능 이미지 데이터 수집)

인공지능 학습용 이미지 데이터를 모으는 웹 페이지입니다.
웹캠으로 직접 찍거나, 여러 장이 모인 사진을 칸별로 잘라서 `클래스이름/1.jpg, 2.jpg …` 형태로 저장합니다.

👉 바로 사용하기: https://keummawon.github.io/image-data-collector/

## 📷 웹캠 촬영 탭
- 범주/클래스 이름을 입력하고 웹캠으로 사진 찍기
  - 버튼을 한 번 누르면 1장, 길게 누르면 연속 촬영
- 이미지 크기 선택 (224 / 400 / 640px 정사각형), 좌우 반전
- 찍은 사진 목록 확인, 크게 보기, 삭제 (키보드 ← → 이동, Delete 삭제)
- ↺ 리셋으로 처음부터 다시 시작

## ✂ 사진 나누기 탭
여러 장이 격자로 모인 사진(예: 4줄 × 5장)을 칸마다 잘라 줍니다.

1. 사진을 끌어다 놓거나, 클릭해서 고르거나, Ctrl+V로 붙여넣기
2. 사진 사이의 흰 구분선을 찾아 칸을 자동으로 나눔
   - 구분선이 없으면 가로줄 수와 한 줄에 몇 장인지 직접 입력 (똑같은 크기로 나눔)
3. 필요하면 조절
   - **가장자리 잘라내기**: 사진 위의 번호나 테두리가 남으면 값을 늘리기
   - **크기 / 정사각형**: 224·400·640px 또는 원본 크기
   - 결과 사진을 클릭하면 저장에서 빠지고, 다시 클릭하면 돌아옴
4. 범주/클래스 이름을 쓰고 **⬇ 폴더에 저장**
5. ↺ 리셋으로 넣은 사진과 설정을 처음 상태로

AI나 API 키 없이 브라우저 안에서만 처리하므로 무료이고, 사진이 인터넷으로 전송되지 않습니다.

## 💾 저장 방식
- **크롬·엣지(PC)**: 상단의 📁 저장 폴더 연결 버튼으로 폴더를 한 번 고르면, 그 안에 클래스 이름 폴더가 바로 만들어져 저장됩니다.
  - 예: `바탕화면 > 사과 > 1.jpg, 2.jpg …`
  - 같은 이름 폴더가 있으면 `사과 (2)`처럼 새 폴더로 저장
  - 다른 위치로 바꾸려면 상단의 **변경** 클릭
- **그 외 브라우저**: `클래스이름.zip` 파일로 다운로드

## 실행 방법
위의 사이트 주소로 접속하거나, `index.html`을 크롬에서 열면 됩니다. 설치할 것은 없습니다.
